# Audio Files

Place three royalty-free audio files here before the demo.

| Filename       | Theme     | Source suggestion                                      |
|----------------|-----------|--------------------------------------------------------|
| matrix.mp3     | Matrix    | freemusicarchive.org — search "cyberpunk industrial"   |
| starwars.mp3   | Star Wars | incompetech.com — "Fanfare for Space" by Kevin MacLeod |
| lotr.mp3       | LOTR      | freemusicarchive.org — search "orchestral fantasy"     |

## License requirements

Only CC0 or CC BY licenses are acceptable.
CC BY-NC is NOT acceptable (prohibits hackathon/commercial use).

Create a `license.txt` in this directory with:
  Track name | Artist | License | Source URL

## If no audio files are present

The app works fine without audio — theme selection and crawl still work,
the audio element will silently fail to load and no error is shown to the user.
